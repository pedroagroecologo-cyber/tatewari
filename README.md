# Tatewari

Agente local de revisión sistemática de literatura científica.

Tatewari acompaña el proceso de una revisión sistemática siguiendo la guía
**PRISMA 2020**: búsqueda, cribado, elegibilidad, extracción y síntesis, dejando
trazabilidad de cada decisión.

## Ejecución 100 % local

Todo el razonamiento se ejecuta en la máquina del usuario sobre
[Ollama](https://ollama.com). No se envía el corpus ni los textos a ningún
servicio externo.
